# GL19 实车验证清单

对象：2019 款帝豪 GL / GKUI / Android 4.4.2 / 车机热点 + Android 蓝牙 / iPhone 无线 CarPlay。
工件：`dist/legacy/CarLink-Legacy-<版本>-ARMv7.apk`（当前 0.1.5，versionCode 8）。
前提：包内已注入 CarPlay 认证资产（`assembleStandaloneRelease` 构建）；车机蓝牙里已配对 iPhone。

每一步都在停车状态操作。**"通过"只算实测结果，不算代码推断。**

## 0. 装包

1. APK 拷到 U 盘 → 车机文件管理器打开 → 允许未知来源 → 安装。
2. 应用列表出现 **CarLink Legacy**，图标可点开。
3. 若之前装过旧版本：直接覆盖安装，设置保留。

通过标准：能装上、能打开，不闪退；设置 → 关于 里的版本号与 APK 一致。

## 1. 首页与自检

打开 CarLink Legacy，看状态卡：

| 自检行 | 含义 | 下一步 |
|---|---|---|
| 自检：就绪，可以连接 | 前置条件齐 | 直接进第 2 步 |
| 自检：自动连接已关闭 | 首页开关没开 | 打开"打开 CarLink 时连接" |
| 自检：还没有保存车机热点信息 | 没读热点 | 点"读取车机热点" |
| 自检：还没有选择 iPhone | 没选手机 | 点"选择 iPhone" |
| 自检：蓝牙未开启 | 车机蓝牙没开 | 车机设置里开蓝牙 |
| 自检：车机热点未开启（可打开下方自动开关） | 热点没开且没授权自动开 | 开"自动开启车机热点"或手动开热点 |
| 自检：认证信息不可用，无法连接 CarPlay | 包内没有认证资产 | 换带认证资产的包，联系开发 |

通过标准：这一行与实际情况一致；点"连接自检"能看到完整报告。

## 2. 首次手动连接

0. 首次打开会弹“三步设置”引导，按提示做即可。
1. 点"选择 iPhone" → 选已配对的 iPhone（状态行显示已选手机）。
2. 点"读取车机热点" → 提示已保存（车机热点开着时）。
3. 点"连接 CarPlay"。

通过标准（按重要性排序）：
1. 进入 CarPlay 画面（不是停在连接页）。
2. 音乐能播、导航能出声。
3. 车机屏幕触控能操作 CarPlay。
4. 手机端出现"正在使用 CarPlay"。
5. 在 CarPlay 画面按返回 / 打开设置：应回到 CarLink Legacy 的首页 / 设置页，**不应**出现 DiPlay 的界面。

记录：从点连接到出画面的秒数。

## 3. 自动连接（核心场景）

1. 首页打开三个开关：**打开 CarLink 时连接 / 自动开启车机热点 / 车机启动后打开**。
2. 在车机设置里**关掉热点**。
3. 熄火、锁车、等 30 秒，再上电。

通过标准：不碰屏幕，DiPlay 自动打开 → 热点被开启 → CarPlay 出画面。
记录：上电到出画面的秒数；中途是否出现"车机热点未开启"对话框（不应该出现）。

再测一次"热点本来就开着"的情况：不应出现多余的热点开关动作。

## 4. 断线恢复

1. CarPlay 正常显示中，进车机设置把热点关掉（或让车机睡眠再唤醒，若该固件会关 AP）。
2. 回到 CarLink。

通过标准：1–2 分钟内热点被重新打开、CarPlay 自动回到画面，不点屏幕。

## 5. 手动断开要保持断开

1. CarPlay 连接中，回到 CarLink 首页点"断开"。
2. 等 2 分钟。

通过标准：不会自己又连上；首页自检行显示"已手动断开，自动连接暂停中"（10 分钟内有效）。

## 6. 失败取证

任何一步没通过：

1. 设置 → 诊断 → **导出诊断报告**。
2. 记下弹窗里的完整路径（优先 U 盘根目录下的 `DiPlay-diagnostics/`）。
3. 把 `CarLinkLegacy-report-*.txt` 传回，并说明：卡在哪一步、当时屏幕显示什么、是否手动点过什么。

报告里已经包含：设备/系统、连接方式、热点模式与状态、三个自动开关、画面/音频偏好、MFi 认证是否可用、自动连接自检与最近动作、开机广播来源、音频统计，以及脱敏后的 `diplay.log`。

## 7. 判定表

| 项目 | 通过条件 |
|---|---|
| 安装 | 可安装、可启动、版本正确 |
| 首页 | 自检行与实际一致；不闪退 |
| 手动连接 | 3 次里至少 3 次进入 CarPlay 画面 |
| 自动连接 | 3 次冷启动里 3 次无人值守进入 CarPlay |
| 断线恢复 | 热点被关后 1–2 分钟内自行恢复 |
| 手动断开 | 10 分钟内不自动重连 |
| 原车功能 | 原车蓝牙、原车语音、车机设置未受影响 |

## 8. 已知限制（不属缺陷）

- 只支持 CarPlay；Android Auto、多手机切换、浮动切换器未移植到 Legacy。
- 热点开关依赖固件允许应用调用隐藏接口；不允许时会退回"请手动开启"。
- 4.4.2 上开启热点可能关闭 Wi-Fi 客户端（原厂 AP/STA 互斥行为）。
- 认证身份为实验性材料，不保证未来 iOS 继续接受。
